# Realee Lead Desk: the rebuild

Clief Notes Weekly Comp #15, "The Rebuild". This is our Comp #14 entry, [realee-lead-desk-control](https://github.com/Realeeai/realee-lead-desk-control), rebuilt from the judge's feedback and tested old against new.

The repo is built in Comp #15's order, one commit at a time: the feedback and the questions first, then the original pinned and run, then the rebuild and its runs, then the results. `git log` shows each step.

So far: [`feedback.md`](feedback.md) and [`questions.md`](questions.md).
