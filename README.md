The repo is built in Comp #15's order, one commit at a time: the feedback and the questions first, then the original pinned and run, then the rebuild and its runs, then the results. `git log` shows each step.

So far: [`feedback.md`](feedback.md), [`questions.md`](questions.md), and [`original/`](original/), the judged folder copied byte for byte from realee-lead-desk-control at commit `a887b92`, the last commit before the Comp #14 deadline (`git archive a887b92:lead-desk`). It's read only here.
